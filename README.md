# 📦 QuickStock - Gestor de Inventario (Prueba de Concepto)

QuickStock es un sistema de escritorio sencillo para la gestión de inventarios, desarrollado como prueba de concepto para el curso universitario.  

En esta versión inicial se implementan **dos requisitos funcionales**:  
1. Crear artículos en el inventario.  
2. Exportar artículos a Excel.  

---

## 🚀 Tecnologías usadas
- **Lenguaje:** Python  
- **Interfaz gráfica:** Tkinter  
- **Manejo de datos:** Pandas  
- **Almacenamiento:** Archivos CSV  
- **Exportación:** Excel (xlsx)
